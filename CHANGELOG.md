# Changelog

## v0.2.11

### Breaking changes — existing documents and projects need updating

- **`header` renamed `header1`** everywhere. It is only ever printed on page 1
  (first-page-only page style in PDF, `page == 1` guards in Typst), and the
  name now says so.
  - Div: `::: header` → `::: header1`.
  - Metadata: `let-header` → `let-header1`, `meet-header` → `meet-header1`,
    `doc-header` → `doc-header1`.
  - Internal template variable: `page-header` → `page1-header` (layouts for
    HTML, PDF, Typst, md and plain text; `footer` / `page-footer` unchanged).
  - `_parts/` override files: `header.qmd` → `header1.qmd`, in the base,
    `document` and `lesgrandsvoisins` parts. A project-level
    `_parts/header.qmd` is no longer picked up.
  - docx: the `Letter Header` style is now mapped from `header1`.
  - Updated accordingly: `template.qmd`, `_templates/*`, the `lettre/`,
    `compte-rendu/`, `document/` and `gdvoisins/` starter projects, `test/`,
    `README.md`, and the `validate.lua` allow-lists.
- **`clean-artifacts.sh` replaced by `clean-artifacts.lua`.** Any
  `post-render:` entry in a project `_quarto.yml` must point at the `.lua`
  script (updated in `_quarto.yml`, `document/_quarto.yml` and
  `_extensions/base/resources/_quarto.yml`). It is now swept at any depth, and
  `_parts/` (including `custom.cls`) stays excluded.
- **PDF defaults changed** for `lettre-pdf`, `document-pdf` and
  `compte-rendu-pdf`: `toc`, `lof` and `lot` are now `true` (were `false`),
  with `toc-depth: 7`, `number-sections: true`, `number-depth: 5`,
  `colorlinks`, `link-citations` and `link-bibliography`. Set them back to
  `false` in the document to restore the old output. (`lettre`/`document`
  extensions; `compte-rendu` keeps its own settings.)
- **HTML: `wrap: none`** added to `lettre` and `document` HTML formats, so
  pandoc no longer re-wraps generated HTML source.
- **`preamble.tex` moved.** `document/pdf/_partials/preamble.tex` and
  `lettre/pdf/_partials/preamble.tex` are deleted; the shared LaTeX preamble
  now lives in `base/pdf/preamble.tex` and is listed in each extension's
  `format-resources`. A project that overrode the old per-extension file must
  move its overrides.
- **`document`/`lettre` HTML typography**: hard-coded heading sizes
  (`.document h1/h2/h3`), paragraph line-height and the `1.4rem`/`1.6rem`
  title font sizes were removed from `document/html/css/styles.css` and
  `compte-rendu/html/css/styles.css`; sizing now comes from the new shared
  `base/html/css/typography.css` (driven by brand/metadata). Custom CSS
  relying on the old values may need adjusting.
- **Bibliography ordering** (`base/resources/biblio.csl`): the entry sort now
  goes by date (`<key macro="date"/>`); the citation-label sort key is
  commented out. Bibliography `group display="indent"` wrappers were removed,
  so entries are no longer indented by the style.
- The committed Bootstrap/Quarto HTML libraries in `_lib/` were removed from
  the repository (regenerated by Quarto on render).

### Changed (existing files)

- **`base/_filters/page.lua`**
  - `header1` replaces `header` in the fallback/priority class tables and
    stores its content under `page1-header` (new `KEY_FOR_CLASS` mapping).
  - Fonts: brand typography now also provides size, line-height and heading
    weight, and the document metadata overrides the brand
    (`mainfont`, `sansfont`, `monofont`, `headingfont`, `fontsize`,
    `linestretch`, `parskip`). Precedence: metadata > brand.yml > built-in
    IBM Plex defaults.
  - HTML fonts: one Google Fonts `<link>` per family (a single unknown family
    used to make the whole request fail with a 400); bundled font files are
    used when present instead of a Google request; skipped for the web-html
    formats (`webhtml` set).
  - PDF fonts: the previously commented-out `header-includes` font injection
    is back, via `fontspec` (bundled families loaded by file path, others
    guarded with `\IfFontExistsTF`); LaTeX font size is snapped to 10/11/12pt
    and passed through `\documentclass`; Typst maps `mainfont`, `fontsize` and
    a new `QLleading` from the line-height.
  - Margins: new `margins:` CSS-style shorthand (1–4 values) and
    `margin-left`/`margin-right` synonyms of `margin-inner`/`margin-outer`.
  - New heading-spacing metadata: `heading-space`, `heading-space-above`,
    `heading-space-below` (in em, one value or a per-level list).
- **`quarto-lettre.cls`, `quarto-doc.cls`, `quarto-meet.cls`** (and their
  Typst counterparts): common PDF class code centralised in
  `base/pdf/preamble.tex` — each class shrinks by ~300 lines. Also new
  header/footer geometry hooks (see Added).
- **`document/pdf/layout.tex`**: page 1 now has its own `\geometry`,
  independent of `margin-top`/`margin-bottom`, which apply from page 2 onward
  (`\afterpage{\newgeometry{...}}`); first-page body offset comes from
  `margin-top-first` (fallback `margin-top`, then `45mm`); `fontsize` honoured
  in `\documentclass`.
- **`lettre/pdf/layout.tex`, `compte-rendu/pdf/layout.tex`**: same
  `fontsize`/`page1-header` changes; the first page's margins stay fixed
  (sized for header/footer), body pages use `margin-top`/`margin-bottom`.
- **`document/_filters/validate.lua`**: new accepted keys — `doc-header1`,
  `doc-subject`, `margin-top-first`, `margin-header`, `margin-footer`,
  `header-height`, `header-gap`, `footer-height`, `footer-gap`,
  `sidenote-width`, `sidenote-gap`, `sidenote-margin`, `margin-left`,
  `margin-right`, `margins`, `page1-header`, `environments`; `doc-header`
  and `page-header` no longer recognised.
- **`document`, `lettre`, `compte-rendu` `_extension.yml`**: version bumped to
  0.2.11; register `../base/html/css/typography.css`, the
  `latex-environment` filter and an `environments:` list (`uplist`,
  `center`); `document` also registers the new `num` and `minipage`
  shortcodes.
- **Starter `_quarto.yml` files** (`lettre/`, `compte-rendu/`, `document/`,
  `gdvoisins/*/`, root): new `render:` globs (`*.qmd`, exclude `*.md` and
  nested project files), `execute-dir: file`, and `firefox-open.lua`
  post-render in place of a bare `firefox ./_output`.
- **`README.md`**: `header1` rename throughout, and new sections on the
  `margins:` shorthand, header/footer spacing, sidenotes, `document`-only
  extras and side-by-side columns.

### Added

- **New formats/extensions**
  - `document-web` (format `document-web-html`) and `lettre-web`
    (`lettre-web-html`): strict lesgrandsvoisins.com look for standalone
    pages (own stylesheet `base/html/web/css/site.css`, `webdoc.css`,
    layout and `webhtml.lua` filter, output extension `.web.html`).
  - `site` (format `site-html`): light/dark Bootstrap themes
    (`site-light.scss`, `site-dark.scss`) and `webfonts.lua` for small
    Quarto websites; demo in `test/site-demo/`.
  - `latex-environment` (vendored from `quarto-ext`, with its LICENSE):
    turns divs/spans into LaTeX environments.
- **Shortcodes**: `{{< mp-begin >}}` / `{{< mp-next >}}` / `{{< mp-end >}}`
  for side-by-side PDF columns (`width`, `columns`, `border`, `gutter`
  options), and `{{< num >}}` (automatic counter).
- **PDF layout keys** (all three extensions): `margin-header`,
  `margin-footer`, `header-height`, `header-gap`, `footer-height`,
  `footer-gap`, and the sidenote trio `sidenote-width`, `sidenote-gap`,
  `sidenote-margin`; `document` only: `margin-top-first`.
- **Fonts**: bundled families under `_parts/lesgrandsvoisins/fonts/`
  (Fengardo, Fengardo Neue, Fira Sans, Lack) with a shared
  `base/_filters/bundled_fonts.lua` that emits `@font-face` rules for HTML
  and `fontspec` paths for PDF.
- **Scripts**: `base/scripts/firefox-open.lua` (opens the output folder of
  what was just rendered) and `base/scripts/clean-artifacts.lua`.
- **`base/html/css/typography.css`**: shared HTML typography.
- Test material: PDF/ptc outputs and updated sources in `test/`.

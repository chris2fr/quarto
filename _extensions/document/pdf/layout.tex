% Page 1 gets its own geometry, independent of margin-top/margin-bottom (used
% from page 2 onward — see the \afterpage{\newgeometry{...}} call below,
% mirroring lettre/compte-rendu's own first-page/body-pages split): with
% `includehead`, `top` here means "distance from the page's top edge to the
% top of the header" directly, so margin-header controls it with no
% contribution from margin-top — negative \vspace* can't reliably cancel a
% large `top` (TeX silently discards negative glue at the very start of a
% box's content), so decoupling via two geometries, not vspace math, is what
